# Domain Docs

This is a single-context repository.

Before exploring, read the root `CONTEXT.md` and relevant ADRs under `docs/adr/`. If either is absent, proceed silently.

Use canonical terms from `CONTEXT.md` in issues, specifications, tests, and design work. Avoid synonyms rejected by the glossary.

If proposed work conflicts with an ADR, identify the conflict explicitly rather than silently overriding it.
