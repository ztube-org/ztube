# Issue tracker: GitHub

Issues and specs for this repo live as GitHub issues. Use the `gh` CLI for all operations and infer the repository from `git remote`.

## Conventions

- Create, read, comment on, label, and close issues using `gh issue`.
- When a skill says “publish to the issue tracker”, create a GitHub issue.
- When a skill says “fetch the relevant ticket”, read the issue and its comments.
- Pull requests are not a triage request surface.
- GitHub issues and pull requests share a number space; resolve ambiguity before acting.
